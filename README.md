# Storage Estimator

## Purpose
A Python program designed to calculate storage space requirements and convert digital storage units (GB to MB and Bytes).

## How to Run
Run the script using Python in your terminal:

```bash
python storage_estimator.py
```

## Example Input/Output

```text
Enter storage in GB: 2
Storage in MB: 2048.0
Storage in Bytes: 2147483648.0
```
